# Лабораторна робота №1 (Варіант 5 — City)



## Висновок:
У ході лабораторної роботи було створено консольний проєкт lab1v5 та реалізовано клас 
City з приватними полями, публічними властивостями, конструктором та методом GetInfo(). Створено об'єкти класу та продемонстровано їхню роботу в консолі.

## Контрольні запитання:
1. **Що таке клас та об'єкт? Яка між ними різниця?**
   Клас — це шаблон (креслення), який описує структуру та поведінку. Об'єкт — це конкретний екземпляр цього класу, створений у пам'яті за цим шаблоном.
2. **Для чого використовуються конструктори? Чи може клас існувати без них?**
   Конструктори використовуються для ініціалізації початкового стану об'єкта під час створення. Якщо розробник не написав конструктор,
   C# автоматично надає стандартний конструктор без параметрів.
4. **Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?**
   Приватне поле доступне лише всередині класу, а публічна властивість надає контрольований доступ (через get/set) до цього поля ззовні.
   Інкапсуляція потрібна для захисту даних від некоректних змін та приховування внутрішньої логіки.
