# Лабораторна робота №6 (Варіант 5 — BankAccount)

**Тема:** Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

**Мета:** Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new.

---

## Хід роботи

У ході виконання лабораторної роботи я створив консольний проєкт `lab6v5` та реалізував ієрархію класів із базовим `BankAccount` і похідними `SavingsAccount` та `CheckingAccount`. Для передачі параметрів у базовий конструктор використав ключове слово `base`, а також додав власні унікальні методи `AddInterest()` та `ProcessCheck()`. Перевизначив віртуальний метод `Deposit()` через `override`. Для демонстрації приховування членів створив метод `GetAccountType()` з модифікатором `new` у класі `SavingsAccount`. У методі `Main` перевірив роботу унікальних методів, поліморфну поведінку через масив `BankAccount[]` та різницю між `override` і `new`.
