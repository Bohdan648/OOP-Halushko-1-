# Лабораторна робота №5 (Варіант 5 — Animal)

**Тема:** Поліморфізм: динамічне зв'язування та перевизначення методів.

**Мета:** Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів та їх перевизначення, а також агрегувати результати поліморфних викликів.

---

## Хід роботи

У ході виконання лабораторної роботи я створив консольний проєкт `lab5v5` та реалізував ієрархію класів із базовим `Animal` і похідними `Lion`, `Elephant` та `Bird`. Для передачі параметрів у базовий конструктор я використав ключове слово `base`, а також додав власні унікальні властивості для кожного класу та перевизначив віртуальний метод `MakeSound()` через `override`. У методі `Main` я створив колекцію `List<Animal>`, пройшовся по ній у циклі `foreach` та агрегував результати виклику віртуального методу `MakeSound()`, продемонструвавши динамічне зв'язування та поліморфну поведінку.
