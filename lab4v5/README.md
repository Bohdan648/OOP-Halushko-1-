# Лабораторна робота №4 (Варіант 5 — BankAccount)

**Тема:** Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

**Мета:** Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new.

---

## Хід роботи

1. Я створив новий консольний проєкт `lab4v5` у загальній директорії проєкту.
2. Реалізував ієрархію класів банківських рахунків:
   * Створив базовий клас `BankAccount`, у якому оголосив властивості `AccountNumber` і `Balance`, конструктор для їх ініціалізації, а також віртуальний метод `Deposit()`.
   * Створив два похідні класи `SavingsAccount` та `CheckingAccount`. Для ініціалізації базових полів у їхніх конструкторах використав виклик `base(...)`.
   * У похідних класах перевизначив віртуальний метод `Deposit()` за допомогою ключового слова `override` та додав власні унікальні методи (`AddInterest()` для нарахування відсотків та `ProcessCheck()` для обробки чека).
   * Для демонстрації приховування членів додано метод `GetAccountType()` у базовий клас, а в класі `SavingsAccount` приховав його за допомогою модифікатора `new`.
3. У методі `Main` продемонстрував роботу ієрархії:
   * Викликав унікальні методи похідних класів для перевірки їх функціональності.
   * Створив масив базового типу `BankAccount[]` із об'єктами різних класів та викликав метод `Deposit()`, продемонструвавши поліморфну поведінку.
   * Продемонстрував різницю між `override` та `new`, викликавши метод `GetAccountType()` через посилання типу `SavingsAccount` та через посилання базового типу `BankAccount`.

## Відповіді на контрольні запитання

1. **Принцип наслідування:** Дозволяє створити новий (похідний) клас на основі існуючого (базового), успадковуючи його функціональність та розширюючи або змінюючи її. *Приклад:* Клас `Vehicle` (автомобіль, мотоцикл) успадковує загальні властивості типу `Brand` чи `Speed`.
2. **Ключове слово `base`:** Використовується для доступу до членів базового класу з похідного, а саме для виклику його конструктора (`: base(...)`) або успадкованих методів (`base.Method()`).
3. **Різниця між `virtual` та `override`:** `virtual` дає дозвіл на перевизначення методу в базовому класі, а `override` надає його нову реалізацію в похідному. Разом вони забезпечують поліморфізм (динамічне/пізнє зв'язування).
4. **Модифікатор `new`:** Використовується для явного приховування члена базового класу без його перевизначення. Метод обирається за типом посилання (статичне/раннє зв'язування), а не за реальним типом об'єкта.
