# Лабораторна робота №3 (Варіант 5 — GraphicsContext)

**Тема:** Життєвий цикл об'єкта та керування ресурсами.  


**Мета:** Поглибити розуміння життєвого циклу об'єкта в С#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс IDisposable та патерн Dispose.

---

## Хід роботи

1. Створено консольний проєкт `lab3v5`.
2. Реалізовано клас `GraphicsContext` із підтримкою інтерфейсу `IDisposable` та патерну `Dispose`.
3. У методі `Main` продемонстровано три сценарії використання ресурсів:
   - Автоматичне звільнення ресурсу через оператор `using`.
   - Явний виклик методу `Dispose()`.
   - Демонстрація роботи деструктора (фіналізатора) через `GC.Collect()`.

## Відповіді на контрольні запитання

1. Етапи існування об'єкта: виділення пам'яті й виклик конструктора, використання за посиланням, позначення GC для видалення та фіналізація з очищенням пам'яті.
2. Керовані ресурси (пам'ять .NET) очищаються автоматично GC, а некеровані (файли, сокети, БД) вимагають явного звільнення розробником.
3. Для реалізації методу `Dispose()`, який дозволяє негайно звільняти некеровані ресурси.
4. Гарантує виклик `Dispose()` при виході з блоку коду, навіть якщо виникла помилка.
5. Повідомляє GC скасувати виклик деструктора, оскільки ресурси вже звільнені вручну.
6. `Dispose(true)` звільняє керовані й некеровані ресурси при явному виклику; `Dispose(false)` — тільки некеровані ресурси при виклику з деструктора.
