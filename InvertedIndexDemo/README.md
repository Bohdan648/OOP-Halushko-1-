# InvertedIndexDemo

Самостійна робота №16.

Програма демонструє інвертований індекс, пошук одного слова, AND та OR. Також порівнює лінійний пошук із пошуком через індекс для 10 і 1000 документів.

## Запуск

У терміналі папки проєкту виконати:

```bash
dotnet run -c Release
```

## Приклад виводу

```text
Документів: 5
Унікальних слів: 31

Одне слово: C#
[1] Introduction to C#
[4] C# Advanced Features
[5] Comparing Languages

AND: c# async
[4] C# Advanced Features

OR: java python
[2] Java Basics
[3] Python Overview
[5] Comparing Languages

Пошук C#: середній час одного запиту зі 100 повторень.
| Документів | Лінійний, мс | Індекс, мс | Побудова, мс | Знайдено лінійно/індекс |
|---|---|---|---|---|
| 10 | 0.0308 | 0.0018 | 0.1041 | 6/6 |
| 1000 | 2.1910 | 0.0388 | 5.7107 | 600/600 |
```

Час виконання на різних комп’ютерах може відрізнятися.
