# Лабораторна робота №8 (Варіант 5 — CollectionHelper<T>.GroupBy)

**Тема:** Делегати й лямбда-вирази у практиці колекцій: CollectionHelper<T>.

**Мета:** Навчитися передавати поведінку як параметр через делегати Func, Action, Predicate, будувати на цій основі універсальні операції над колекціями та використовувати лямбда-вирази у практиці ООП.

---

## Хід роботи

У ході виконання лабораторної роботи я створив консольний проєкт `lab8v5` та реалізував статичний узагальнений клас `CollectionHelper<T>`. Відповідно до варіанту 5 було створено метод `GroupBy<TKey>`, який приймає колекцію `IEnumerable<T>` та делегат `Func<T, TKey>` для групування елементів за обраним ключем у `Dictionary<TKey, List<T>>`. Логіка методу написана вручну без використання стандартного LINQ-оператора `GroupBy`. Роботу методу продемонстровано в `Main` на двох різних типах колекцій (`List<Product>` та `List<string>`) із застосуванням лямбда-виразів.
